records remain historical evidence, not results for these new instructions.

## Change and scope

WB09 is an editorial restriction of an **unrequested combined** small-town
homecoming/tradition-revival/instant-reconciliation arc. It does not prohibit
festivals, villages or harmonious outcomes on their own. A new game-specific
heuristic connects the environment to the player's feasible actions when the
gameplay is free to invent, without changing fixed mechanics or atmosphere-only
work. R2–R6 in EVIDENCE.md distinguish observations in literature from
untested interventions for a skill.

## Research and validation boundaries

- R1 reports common lexical tokens in lightly prompted English stories; it
  does not measure the frequency of a particular compound game plot.
- R2/R3 describe narrative echoes and structural regularities; neither
  evaluates a one-pass exclusion checklist as an intervention.
- R4 analyzes literary action/perceived space with imperfect classifiers;
  it does not show that gameplay improves from our proposed positive rule.
- R5 observes one GPT-4o-mini model under nationality-conditioned prompts;
  the WB09 restriction is an **editorial policy**, not a confirmed universal
  model behavior.
- R6 examines special formatting tokens in training/inference; it does not
  show that plain Markdown or user-requested output formats are harmful.

## Reproduce

```powershell
$env:PYTHONUTF8 = '1'
python -m pip install -r requirements-dev.txt
python tools/check.py
python -m unittest discover -s tests -v
python tools/package.py
```

For any new output sample, record its prompt, observed host/model, skill hash,
reviewer, rubric, actual text and limits. A few injected-prompt samples cannot
establish cross-model reliability or a quantitative cliché-reduction rate.
